# AwesomeCUA research survey

Open `index.html` in a browser. It is a complete English working manuscript with embedded CSS, JavaScript, and the original inventory figure. No external runtime dependency is required.

`references.bib` and `references.json` preserve the source editions used. `evidence/reading-index.json` lists every cited source and actual read level. The other JSON ledgers document the search, bounded screening, original claim notes, and inventory analysis. Raw papers, full abstracts, model weights, and training data are not included.

The research inventory is pinned to source commit 87166fe8ad9c8e832f7a90ee84b2e93c6e0e40db and catalog SHA-256 7f71a1683ab013e587a20086c3e357956981f517a24ae8bc8e81791108c66e4f. The generated survey is a working manuscript, not a claim of independent experiment reproduction or peer-reviewed publication. Its intended public location is https://awesomecua.com/survey/; this build does not publish it.
