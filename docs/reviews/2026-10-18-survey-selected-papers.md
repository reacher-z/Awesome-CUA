# Survey-selected paper additions — 18 October 2026

Thirteen papers selected while preparing the English survey were absent from
the active catalog and retained arXiv archive. They are now indexed from the
original, SHA-checked Atom responses. All thirteen complete abstracts were
reviewed; twelve also have exact-version, source-reviewed full-text sections.
WebUIProof is an abstract-reviewed adjacent resource. No experimental results
were reproduced and no code or dataset release was approved by this batch.

| Paper | Annotation boundary |
| --- | --- |
| [WebUIProof](https://arxiv.org/abs/2610.02617v1) | Adjacent browser execution harness for testing generated interfaces. |
| [DIBench](https://arxiv.org/abs/2610.06898v1) | Decision integrity; commercial-app trials use fixed screenshots and context. Appendix B supplies the Android emulator evidence. |
| [Act2Intention](https://arxiv.org/abs/2608.14132v1) | Intention understanding, prediction and confirmed execution; Section 4.2.2 identifies Android emulation for generated trajectories. |
| [AndroidReality](https://arxiv.org/abs/2608.07775v1) | Controlled AndroidWorld perturbations and introspective recovery. |
| [NeXUI](https://arxiv.org/abs/2608.09944v1) | Explanatory assistance in recorded interface states; reported model trials use text inputs. |
| [Darwin Mobile Agent](https://arxiv.org/abs/2606.20622v1) | Implemented asynchronous Android RL infrastructure is distinguished from the broader self-evolution roadmap. |
| [X-OmniClaw](https://arxiv.org/abs/2605.05765v2) | Android architecture and runtime skill capture; demonstrations do not establish policy-weight imitation learning or completed literal replay. |
| [Curiosity Driven Knowledge Retrieval](https://arxiv.org/abs/2601.19306v1) | Application knowledge retrieval into AppCards, evaluated on AndroidWorld. |
| [Agent+P](https://arxiv.org/abs/2510.06042v3) | Symbolic planning over modeled UI transition graphs; guarantees depend on that representation. |
| [AppCopilot](https://arxiv.org/abs/2509.02444v2) | Coordinate correction, task planning and trace reuse; unsupported OS and latency claims are omitted. |
| [PerPilot](https://arxiv.org/abs/2508.18040v1) | Personalization through instruction completion, memory, exploration and clarification. |
| [ProactiveVA](https://arxiv.org/abs/2507.18165v1) | Adjacent assistance inside instrumented visual-analytics systems. |
| [SafeMobile](https://arxiv.org/abs/2507.00841v1) | Chain-level risk checking and a specific assisted evaluator; its evaluated task population is kept distinct from later benchmark editions. |

The original versions, titles, author order, dates and abstract fingerprints
match the retained primary metadata. Existing archive, primary-evidence and
editorial objects are preserved. An independent AI-assisted review checked
all thirteen annotations and improved the two Android evidence notes above.
Raw abstracts and full texts remain in ignored local evidence storage, outside
the public data changes.

This batch adds thirteen paper records and thirteen reviewed annotations. It
does not change the survey's frozen corpus statistics or retrospectively enlarge
its literature-selection denominator. Discovery observations and active resource
counts remain separate populations.
