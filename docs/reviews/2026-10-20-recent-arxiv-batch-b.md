# Recent arXiv source review, batch B: 20 October 2026

This batch follows up five metadata-only papers from the retained recent arXiv search. It adds no new search-query population. Complete official abstracts were reread after checking titles, ordered authors, first/version timestamps, v1 identities and normalized abstract hashes against the retained bibliography. Selected exact-v1 methods, evaluation and limitation sections were then read from official HTML. The Atom receipt keeps its original retrieval time; five new HTML requests retain separate fingerprints.

| Paper | Reviewed annotation scope | Limits retained in the review |
| --- | --- | --- |
| [Focused Omni-Modal GUI Agents](https://arxiv.org/html/2610.26203v1), 19 October | FocusGUI weights multimodal/context channels and adds a compact residual to a frozen decoder without pruning its original inputs. | Episode-disjoint OmniGUI reference-action evaluation does not establish live task-success gains. Appendix D.1 explicitly specifies Android. |
| [Tandem](https://arxiv.org/html/2610.26660v1), 19 October | Android NPU serving uses prompt-divergence checkpoints, rollback-aware speculation and idle power control. | Trace benchmarks and instrumented real tasks measure serving time, energy and action fidelity. Per-request latency excludes app execution; no improved task-success or general reliability claim follows. |
| [Comparing Computer Use Behavior Across Multiple Levels of Abstraction](https://arxiv.org/html/2610.26703v1), 19 October | MAP labels and compares human/agent traces at several semantic levels. | It is trace analysis, not a new acting policy. Annotation samples, segmentation ambiguity and available timing constrain conclusions. Reduced source-identification accuracy is not a privacy guarantee. |
| [SPIDES](https://arxiv.org/html/2610.24277v1), 16 October | Information-flow labels and approval gates mediate browser-agent actions. | Security properties assume correct labels, trusted origins and trusted tool mediation. Evaluation uses idealized approvals; origin-level reader sets cannot distinguish all recipients within an origin. |
| [MobileInject](https://arxiv.org/html/2610.23307v1), 16 October | Stateful Android workflows combine observation-injection evaluation, application-state oracles and trace diagnostics. | The attacker controls observations rather than system instructions or the OS. Emitted-rationale labels include outcome-dependent constraints and do not establish hidden-reasoning causality. |

The five annotations were independently reviewed and adopted into the catalog. Existing bibliography and versions remain unchanged. Performance results, release completeness and artifact licenses were not independently verified; no project code was executed. Approval records the reviewed source scope rather than following automatically from HTTP success.
