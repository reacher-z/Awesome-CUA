# Interface-evidence follow-up: 20 October 2026

This batch revisits three existing arXiv records after separate source reading
and independent AI-assisted review. It adds no new paper identities and leaves
the retained bibliographic archive unchanged. No linked code, model, dataset or
benchmark was executed.

| Paper | Decision | What the inspected protocol establishes |
| --- | --- | --- |
| [Visible but Not Avoided v1](https://arxiv.org/html/2610.15738v1) | Core; operating system unspecified | A screenshot-only GUI agent predicts tagged taps or text answers on 60 cached development items from nine synthetic apps. The outer optimization loop selects among 40 fixed harness edits. This is component evaluation, not live mobile task completion or evidence of an internal causal mechanism. |
| [Qwen-Planner-Agent v1](https://arxiv.org/html/2609.29892v1) | Core; operating system unspecified | Typed tools change application/device state, with selected real-device sessions alongside programmatic sandboxes and LLM simulation. Pixel-coordinate GUI control is not established. Model/harness refinement is offline; development-set results and unequal memory-access budgets constrain interpretation. |
| [PEAM v1](https://arxiv.org/html/2610.14855v1) | Source-bound reviewer hold | Real Android 16 cellular/Wi-Fi switching and explicit user acceptance are documented. The inspected work does not establish GUI observation/action control or actual use as a CUA component. The hold preserves this positive execution evidence and the original metadata. |

The first two papers' version-specific arXiv infoboxes explicitly declare
CC BY 4.0 for the documents. This does not establish licenses for code, data or
weights. PEAM's document distribution declaration does not grant editorial
approval or establish a permissive implementation license.

The mobile setting does not identify an operating system by itself. Likewise,
using typed tools does not establish the catalog's narrower `tool-integration`
topic, which describes combining GUI actions with tools. Qwen-Planner retains
its supported planning, training, memory, mobile-navigation and efficiency
annotations without that unsupported tag.
